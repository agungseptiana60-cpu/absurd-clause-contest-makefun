One absurd clause, 143 characters, written as deadpan terms-of-service boilerplate: "By accepting these terms, you agree that your internal monologue may be narrated by a retired auctioneer during peak hours, at no extra charge." The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
